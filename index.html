FAQ-Agent zu den B Lab Standards

Frag nach einer Requirement-ID, nach einer Frist oder nach dem, was für deine Unternehmensgrösse gilt. Der Agent antwortet auf Basis des hinterlegten Standardtexts und nennt die Fundstelle.

B Lab Standards · Apertus über Dify, Serverstandort Frankfurt am Main

Was ein Claude Skill ist

Ein Ordner mit einer Anleitung in Klartext und optional Referenzdateien. Claude lädt zuerst nur Name und Beschreibung. Passt die Frage dazu, wird die Anleitung geladen. Referenzdateien erst dann, wenn sie gebraucht werden. Kein Programmcode, kein Fine-Tuning, keine eigene Infrastruktur.

Der praktische Effekt: Fachwissen lässt sich weitergeben wie ein Dokument. Wer es ändern will, bearbeitet eine Textdatei.

Warum Apertus im FAQ-Agenten

Apertus ist ein offenes Sprachmodell von EPFL, ETH Zürich und CSCS. Trainingsdaten, Code, Gewichte und Alignment-Verfahren sind offengelegt. Das Modell läuft self-hosted über Dify auf einem Server in Frankfurt am Main.

Für Mandate mit vertraulichen Unternehmensdaten ist das ein Argument, das sich belegen lässt, statt eines Versprechens.

Die zehn Skills

Der Certification Navigator steuert, die sieben Impact-Topic-Skills arbeiten fachlich zu, zwei Querschnittsskills berichten und überwachen. Jeder Skill lässt sich einzeln herunterladen und in Claude installieren.

Installation in drei Schritten

Die ZIP-Dateien enthalten die SKILL.md im Wurzelverzeichnis, genau so erwartet Claude sie.

Claude Web oder Desktop

  1. Einstellungen → Capabilities → «Code execution and file creation» aktivieren
  2. Customize → Skills → «Create skill» → «Upload a skill»
  3. ZIP-Datei hochladen, zum Beispiel certification-navigator.zip

Claude Code

Repository klonen und die Skill-Ordner ins Skill-Verzeichnis kopieren:

git clone https://github.com/hartmut-ux/ai-bcorp-team.git

cp -r ai-bcorp-team/skills/* ~/.claude/skills/

Danach meldet sich der passende Skill von selbst, sobald eine einschlägige Frage kommt.
